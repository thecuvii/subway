## 项目简介

这是一个展示中国**部分**城市地铁线路的可视化应用，使用现代 Web 技术栈构建，提供交互式的地铁网络浏览体验。

## 技术栈

### 核心技术

- **前端框架**: Vue 3 + Nuxt 3
- **可视化**: Deck.gl
- **状态管理**: Pinia
- **类型检查**: TypeScript
- **构建工具**: Vite


## 数据说明

- 📊 **数据来源**: 高德地铁图城市目录，以及高德 Web 服务公交线路 ID 查询接口；经纬度为 GCJ-02，展示时转换为 WGS84。
- 📅 **数据时间**: 2026年10月1日采集快照。接口没有统一的数据更新时间，采集日期不代表全部线路均已核验至当天。
- 🏙️ **覆盖范围**: 58 个地区、396 条线路记录、8,558 条站点记录。包括地铁、磁浮和有轨电车；支线及跨城线路可能重复计数，部分相邻城市合并展示。这是高德目录覆盖范围，不是独立核实的全国城市普查结果。
- ⚠️ **已知缺失**: 台北淡水信义线（`900000192971`）在高德官方线路接口中返回空结果，本次暂未纳入。猫空缆车属于索道交通，已排除。
- 🧾 **来源与校验**: 详见 [更新报告](./datasource/update-staging/README.md) 和 [数据来源记录](./datasource/metadata.json)。全部已纳入线路均取得真实经纬度轨迹，并核对运营状态及站点与轨迹的距离。

## 数据更新

准备自己的高德 **Web 服务** Key，在项目根目录 `.env.local` 中配置 `AMAP_WEB_SERVICE_KEY`。该文件及原始响应缓存不会进入 Git；Key 仅供本地采集工具使用，不写入前端配置。

```sh
pnpm data:lines       # 下载城市目录和地铁示意图数据
pnpm data:polyline    # 获取官方线路轨迹和站点；保存缓存以便断点续跑
pnpm data:verify      # 校验并暂存，查看 geometry-report.json
pnpm test:data       # 运行数据校验测试
pnpm data:apply      # 备份旧数据并替换正式数据；有未解决线路时拒绝应用
```

若确认接受某条线路缺失，必须明确列出其城市 ID 和线路 ID，例如本次使用的命令：

```sh
pnpm data:apply --omit-line=7101:900000192971
```

旧数据备份存放在 `.data-cache/amap/backups/`。重新执行 `data:lines` 后，早于新目录采集时间的轨迹缓存会重新获取。高德高级接口的权限、额度和速率限制以账号控制台为准，认证或额度错误会终止批量查询。

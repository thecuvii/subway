## 来源与时间

目录及站点示意图：[高德地铁图](https://map.amap.com/subway/index.html)实际使用的公开接口。真实路径、站点及运营状态：[高德官方公交信息查询接口](https://lbs.amap.com/api/webservice/guide/api-advanced/bus-inquiry)。坐标为 GCJ-02，应用展示时转换为 WGS84。

目录采集时间（UTC）：2026-10-01T08:50:17.067Z。本次应用时间（UTC）：2026-10-01T09:50:15.991Z。精确时间以这些 UTC 记录为准。来源没有统一的数据更新时间，采集日期不能解释为全部数据已核实至当天。每个来源的抓取时间、响应 SHA-256、线路类型与距离校验结果保存在 ../metadata.json 和 geometry-report.json 中，未保存 Key。

高德目录包含 58 个地区及部分跨城系统，不是独立核实的全国所有地铁城市清单。支线、跨城线路和站点会重复计数；轻轨、磁浮、有轨电车也在源目录范围内；新北等相邻城市可能归入同一系统。

## 文件与复现

正式数据：../data.json。旧数据备份：.data-cache/amap/backups/7c051d00f203ede9a0d9b7f5be52dab78485253c771d4b9c8f94387477ac03f7.json（项目根目录下，被 Git 忽略）。原始接口响应保存在 .data-cache/amap/。report.json 是补齐轨迹前的初始暂存报告，当前应用结果以 ../metadata.json 和 geometry-report.json 为准。

项目根目录下执行：

```sh
pnpm data:lines
pnpm data:polyline
pnpm data:verify
pnpm test:data
pnpm data:apply --omit-line=7101:900000192971
pnpm build
```

高德 Web 服务 Key 配置在 .env.local 的 AMAP_WEB_SERVICE_KEY 中，不进入前端运行配置。采集支持缓存续跑；重新获取目录后将刷新早于目录时间的轨迹缓存。有未授权省略的失败项时，应用工具拒绝覆盖正式数据。

本次同时修正普通和详情图层重复绘制整条路径的问题，并为普通图层 ID 加上城市前缀，避免跨城同 ID 线路相互覆盖。

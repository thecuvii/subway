# 原有城市的新旧数据对比

对比对象：本次更新前备份与当前 datasource/data.json。比较日期：2026 年 10 月 1 日。旧数据 SHA-256：7c051d00f203ede9a0d9b7f5be52dab78485253c771d4b9c8f94387477ac03f7；新数据 SHA-256：5310cacfa5ad2590fd4da0416c6d99bd5ad0f1feae1868abe0c81bfbc0f9cc73。

## 结论

原有 41 个城市全部保留，内容不是原样保留：这些城市的线路记录从 295 增至 356，站点记录从 6,345 增至 7942。

按同一城市和线路 ID 匹配，289 条旧线路仍在，67 个线路 ID 新增，6 个旧线路 ID 不再出现。ID 不再出现不等于实际线路消失；应结合线路重组、合并和源 ID 变化判断。

289 条可匹配线路中：258 条名称相同，31 条名称改变；279 条颜色相同，10 条颜色改变；91 条站名顺序完全相同，其余 198 条不同。不同的顺序中有 63 条仅为完全反向，63 条具有相同的站名多重集合但顺序不同（包含上述反向情况），不能把这些全部解释成线路增减。

旧数据使用数字站点 ID，新接口使用 BV 开头的站点 POI ID，6,153 条按同一线路和相同站名匹配的站点记录中，没有一个 ID 相同。这是标识体系变化，不能解释成所有站点都被替换。

## 同名站点坐标变化

距离采用经纬度的局部平面近似，以米计；统计包含跨线路重复站点，未按实体站点去重。

| 新旧坐标距离 | 站点记录数 |
|---|---:|
| 不超过 1 米 | 4360 |
| 大于 1 米、不超过 50 米 | 969 |
| 大于 50 米、不超过 250 米 | 763 |
| 大于 250 米 | 61 |

最大偏移约 533 米。较大的例子包括武汉 8 号线徐家棚、昆明 4 号线牛头山和上海 1 号线徐家汇。这些差异可能涉及地铁图坐标与线路站点 POI 位置定义不同，也可能涉及源数据质量，已对 5 个较大偏移站点进行独立抽样核验，4 个支持新坐标，徐家汇仍有精度疑点；详见 [抽样核验报告](./station-audit.md)。其余差异不能全部认定为旧坐标纠错。
